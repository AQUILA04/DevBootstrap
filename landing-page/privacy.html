Qui nous sommes

StackPilot est un produit d’OptimizeSolux. Contact : contact.stackpilot@optimizesolux.com. Site : stackpilot.optimizesolux.com.

Ce que fait StackPilot

StackPilot est un installateur Windows (application Win32) qui aide à installer un pack d’outils de développement que vous sélectionnez (via une interface graphique). Il s’appuie principalement sur winget, et peut aussi activer des composants Windows (WSL / fonctionnalités via DISM) ou télécharger certains SDK (par exemple Flutter) selon le catalogue.

Données que nous collectons

L’application StackPilot elle-même ne collecte pas de compte utilisateur, n’envoie pas de télémétrie propriétaire à OptimizeSolux, et n’héberge pas de backend d’analytics pour l’installateur.

  • Aucun compte StackPilot n’est requis pour utiliser l’application.
  • Aucun identifiant publicitaire n’est généré par StackPilot.
  • Les journaux affichés dans l’interface restent locaux à votre session.

Données traitées localement

Sur votre machine, StackPilot lit le fichier local catalog.json, lance des processus système (winget, éventuellement wsl, dism, téléchargements HTTPS) et écrit uniquement ce que ces outils écrivent déjà (programmes installés, variables d’environnement, etc.).

Logiciels tiers

Lorsque vous cochez un outil (Git, Docker Desktop, IDE, navigateurs, etc.), l’installation est effectuée par des mécanismes tiers (souvent winget) ou par téléchargement depuis l’éditeur. Ces logiciels ont leurs propres politiques de confidentialité, licences et télémétries. OptimizeSolux ne contrôle pas les données que ces éditeurs collectent après installation.

Site web

Le site vitrine peut être servi via un hébergeur / CDN. Les journaux d’accès HTTP standards (adresse IP, user-agent, URL) peuvent être conservés par l’hébergeur pour sécurité et diagnostic, selon sa configuration. Nous ne déposons pas de cookies publicitaires sur la page d’accueil StackPilot.

Microsoft Store et mises à jour

Si vous installez StackPilot depuis le Microsoft Store, Microsoft traite les données liées à l’acquisition Store selon les conditions Microsoft. Les builds de secours signés publiés sur GitHub Releases sont téléchargés depuis GitHub (politique GitHub / Microsoft applicables au téléchargement).

Enfants

StackPilot cible des développeurs et administrateurs de postes Windows. Il n’est pas destiné aux enfants de moins de 16 ans.

Vos choix

  • Vous choisissez les paquets à installer avant de lancer l’installation.
  • Vous pouvez désinstaller StackPilot (Paramètres Windows / MSI / Store).
  • Désinstaller StackPilot ne désinstalle pas automatiquement les outils tiers déjà installés.

Modifications
