StackPilot

Ton poste de dev, prêt en un lancement.

Fini les téléchargements un par un à chaque nouveau PC, mission ou entreprise. Coche ton pack, lance l’installateur — winget s’occupe des dernières versions.

Télécharger le ZIP Voir les étapes

Le problème

Chaque nouveau poste recommence à zéro.

Git, JDK, Docker, IDE, navigateurs, clients SQL, Postman… Sur Windows, tu rejoues la même checklist pendant des heures — liens qui bougent, versions obsolètes, oublis de WSL.

StackPilot centralise ton pack dans un catalogue versionné, avec une interface simple et des installations toujours à jour via winget.

Utilité

Conçu pour les devs qui changent souvent de machine.

Une seule passe

Installe tout le pack ou une sélection. WSL avant Docker, ordres sensibles gérés pour toi.

Toujours à jour

Pas d’URLs figées à maintenir. winget tire la dernière version disponible au moment de l’install.

GUI + CLI

Double-clic sur l’EXE pour les jours pressés, ou bootstrap.ps1 pour automatiser.

Profils metier

Frontend, Backend, Fullstack, DevOps, UX/UI : un pack curate par role, ajustable avant install.

Catalogue ouvert

Le pack vit dans Git. Ajoute tes outils, propose une PR — la communauté enrichit la base.

Démarrer

Quatre étapes, et tu codes.

  1. 01

    Télécharge

    Récupère StackPilot.zip depuis la dernière release GitHub. Garde tous les fichiers du dossier ensemble.

    releases/latest →
  2. 02

    Lance en administrateur

    Double-clic sur StackPilot.exe (UAC). Requis pour WSL et Docker Desktop.

  3. 03

    Choisis un profil

    Base, Frontend, Backend, Fullstack, DevOps ou UX/UI Web Designer — puis ajuste la checklist (PostgreSQL, SQL Developer, etc.).

  4. 04

    Installer

    Laisse tourner. Un redémarrage peut être demandé après WSL. Relance Docker si besoin.

Prérequis : Windows 10/11 avec winget (App Installer).

Communauté

Ajoute les outils que tu utilises vraiment.

StackPilot n’est pas un store fermé. Si ton stack manque d’une brique utile (SDK, CLI, IDE, client DB…), propose-la dans le catalogue partagé.

  • Fork le dépôt
  • Ajoute une entrée dans catalog.json avec l’ID winget
  • Branche-la dans un profil (frontend, backend…)
  • Ouvre une Pull Request
