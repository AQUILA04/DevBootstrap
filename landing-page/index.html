StackPilot

Ton poste de dev, prêt en un lancement.

Coche un profil métier, ajuste la checklist, lance l’installateur. winget tire toujours les dernières versions.

Télécharger le ZIP Voir les étapes

Le problème

Chaque nouveau poste recommence à zéro.

Git, JDK, Docker, IDE, Flutter, clients SQL, Postman… Sur Windows, tu rejoues la même checklist pendant des heures — liens qui bougent, versions obsolètes, oubli de WSL.

StackPilot centralise ton pack dans un catalogue versionné, avec une interface simple et des installs toujours à jour.

Profils

Un pack curaté par métier.

Choisis un rôle, puis affine. Rien n’est figé.

  • BaseSocle commun
  • FrontendNode, navigateurs, Figma
  • BackendJDK, Docker, Postgres
  • FullstackFrontend + Backend
  • DevOpsK8s, Terraform, cloud CLI
  • MobileAndroid Studio, Flutter
  • UX/UIFigma, GIMP, ShareX

Une seule passe

WSL avant Docker, Flutter après le JDK — l’ordre sensible est géré pour toi.

Toujours à jour

Pas d’URLs figées. winget tire la dernière version au moment de l’install.

GUI + CLI

Double-clic sur l’EXE, ou bootstrap.ps1 -Profile mobile pour automatiser.

Catalogue ouvert

Le pack vit dans Git. Propose une PR — la communauté enrichit la base.

Démarrer

Quatre étapes, et tu codes.

  1. 01

    Télécharge

    Récupère StackPilot.zip depuis la dernière release. Garde tous les fichiers ensemble.

    releases/latest →
  2. 02

    Lance en administrateur

    Double-clic sur StackPilot.exe (UAC). Requis pour WSL et Docker Desktop.

  3. 03

    Choisis un profil

    Base, Frontend, Backend, Fullstack, DevOps, Mobile ou UX/UI — puis ajuste la checklist.

  4. 04

    Installer

    Laisse tourner. Un redémarrage peut être demandé après WSL.

Prérequis : Windows 10/11 avec winget (App Installer).

Communauté

Ajoute les outils que tu utilises vraiment.

Si ton stack manque d’une brique (SDK, CLI, IDE, client DB…), propose-la dans le catalogue partagé.

  • Fork le dépôt
  • Ajoute une entrée dans catalog.json
  • Branche-la dans un profil
  • Ouvre une Pull Request
