# Ressources Microsoft Store

Les logos PNG sont générés à partir de l'identité visuelle StackPilot avec :

```powershell
python .\scripts\generate-store-assets.py
```

- `StackPilot-512.png` : logo source haute résolution
- `StackPilot-300.png` : logo de fiche Store
- `StackPilot-150.png` : tuile carrée
- `StackPilot-44.png` : petit logo

Ajouter avant la première soumission au moins trois captures propres de
l'application en 16:9 ou 16:10. Ne pas utiliser une capture montrant une alerte
SmartScreen ou des informations propres à une machine.

Quand Partner Center fournit l'URL produit définitive, remplacer l'URL de
recherche `https://apps.microsoft.com/search?query=StackPilot` dans le site et
le README par cette URL.
